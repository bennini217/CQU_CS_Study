# 红酒数据集winequality-red.csv简介

## 数据集概述
本仓库提供的红酒数据集winequality-red.csv包含了1599个红酒样本的相关理化性质及品质评分。该数据集是进行红酒品质分析、理化特性研究以及机器学习项目中的宝贵资源。

## 数据内容
数据集具体包含了以下11个理化性质指标：
- fixed acidity（非挥发性酸）
- volatile acidity（挥发性酸）
- citric acid（柠檬酸）
- residual sugar（剩余糖分）
- chlorides（氯化物）
- free sulfur dioxide（游离二氧化硫）
- total sulfur dioxide（总二氧化硫）
- density（密度）
- pH（酸碱性）
- sulphates（硫酸盐）
- alcohol（酒精）

以及一个红酒品质评分，评分范围从0到10。

## 数据集应用
此数据集可应用于：
- 红酒品质预测
- 数据可视化分析
- 机器学习模型训练
- 统计分析
