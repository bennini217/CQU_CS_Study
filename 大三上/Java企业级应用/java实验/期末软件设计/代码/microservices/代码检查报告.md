## 二、发现的问题 ⚠️

### 问题1：Feign客户端定义但未使用（信息说明）

**位置**：
- `grade-service/src/main/java/com/student/grade/GradeServiceApplication.java`
- `grade-service/src/main/java/com/student/grade/controller/GradeController.java`

**问题描述**：
- grade-service中定义了`StudentServiceClient` Feign客户端接口
- 但是`@EnableFeignClients`注解被注释掉了
- GradeController中StudentServiceClient的导入和使用也被注释掉了
- 实际使用的是本地的`StudentMapper`，代码中有注释说明："使用本地Mapper查询，更快且不依赖其他服务"

**影响**：这是一个**有意的设计决策**，不是bug。如果未来需要使用Feign调用student-service，需要：
1. 取消@EnableFeignClients注释
2. 取消GradeController中的相关注释

**建议**：
- 如果不需要Feign调用：可以删除StudentServiceClient接口，保持代码简洁
- 如果需要Feign调用：取消相关注释即可

**状态**：设计决策，非bug
