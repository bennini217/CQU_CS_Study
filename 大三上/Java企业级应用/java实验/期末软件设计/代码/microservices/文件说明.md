# Microservices 目录文件说明

## 一、目录结构概览

```
microservices/
├── pom.xml                    # 父POM文件（Maven多模块项目管理）
├── README.md                  # 项目说明文档
├── init_database.sql         # 数据库初始化脚本
├── 改造总结.md                # 架构改造总结文档
├── common/                    # 公共模块
├── user-service/              # 用户认证服务
├── student-service/           # 学生服务
├── grade-service/             # 成绩服务
├── teacher-service/           # 教师服务
├── ai-service/                # AI服务
└── gateway-service/           # API网关服务
```

---

## 二、根目录文件说明

### 1. pom.xml（父POM文件）⭐ **关键文件**
**作用**：
- 管理整个微服务项目的Maven多模块结构
- 统一管理所有子模块的版本和依赖
- 定义Spring Boot、Spring Cloud、Spring Cloud Alibaba等版本
- 声明所有子模块（common、user-service、student-service等）

**为什么关键**：
- 这是Maven多模块项目的基础，没有它无法构建整个项目
- 统一管理依赖版本，避免版本冲突

### 2. README.md
**作用**：
- 项目说明文档
- 包含快速开始指南、环境要求、启动步骤等

### 3. init_database.sql
**作用**：
- 数据库初始化脚本
- 创建数据库表结构
- 可选的初始化数据

### 4. 改造总结.md
**作用**：
- 记录从单体应用到微服务架构的改造过程
- 架构对比、技术栈对比、改造优势等

---

## 三、各服务模块详细说明

### 1. common/（公共模块）⭐ **关键模块**

**作用**：所有微服务共享的公共代码

**主要文件**：
- `pom.xml`：公共模块的Maven配置
- `Result.java`：统一响应结果封装类（所有API返回格式）
- `entity/`：实体类（User、Student、Teacher、Grade等）
- `dto/`：数据传输对象（LoginDTO、ChangePasswordDTO等）
- `util/`：工具类（PasswordUtil、SqlInjectionProtection）
- `annotation/`：自定义注解（RequireAuth、RequireRole）

**为什么关键**：
- 所有服务都依赖common模块，保证数据模型一致性
- 避免代码重复，提高可维护性

---

### 2. user-service/（用户认证服务）

**作用**：处理用户登录、密码修改等认证相关功能

**关键文件**：
- `pom.xml`：服务依赖配置
- `UserServiceApplication.java`：服务启动类（端口8081）
- `application.yml`：服务配置文件（端口、数据库、Nacos配置）
- `controller/LoginController.java`：登录和密码修改接口
- `mapper/UserMapper.java`：用户数据访问接口

**端口**：8081

**主要接口**：
- `POST /api/login`：用户登录
- `POST /api/change-password`：修改密码

---

### 3. student-service/（学生服务）

**作用**：提供学生信息查询功能

**关键文件**：
- `pom.xml`：服务依赖配置
- `StudentServiceApplication.java`：服务启动类（端口8082）
- `application.yml`：服务配置文件
- `controller/StudentController.java`：学生信息查询接口
- `mapper/StudentMapper.java`：学生数据访问接口

**端口**：8082

**主要接口**：
- `GET /api/student/{studentId}`：根据学生ID查询学生信息

**特点**：被其他服务（如grade-service）通过Feign调用

---

### 4. grade-service/（成绩服务）⭐ **核心业务服务**

**作用**：处理成绩相关的所有业务功能

**关键文件**：
- `pom.xml`：服务依赖配置
- `GradeServiceApplication.java`：服务启动类（端口8083）
- `application.yml`：服务配置文件（包含Feign超时配置）
- `controller/GradeController.java`：成绩查询、课程表查询接口
- `controller/DashboardController.java`：仪表盘统计接口
- `mapper/`：多个Mapper接口（GradeMapper、TeachingClassMapper等）
- `client/StudentServiceClient.java`：⭐ **Feign客户端**（调用student-service）

**端口**：8083

**主要接口**：
- `GET /api/grade/list`：查询学生成绩列表
- `GET /api/grade/class`：查询班级成绩
- `GET /api/grade/timetable`：查询课程表
- `GET /api/dashboard/student`：学生仪表盘统计
- `GET /api/dashboard/teacher`：教师仪表盘统计

**为什么关键**：
- 这是核心业务服务，包含最复杂的业务逻辑
- 演示了服务间调用（通过Feign调用student-service）

---

### 5. teacher-service/（教师服务）

**作用**：处理教师相关的业务功能

**关键文件**：
- `pom.xml`：服务依赖配置
- `TeacherServiceApplication.java`：服务启动类（端口8084）
- `application.yml`：服务配置文件
- `controller/TeacherController.java`：教师相关接口
- `mapper/`：Mapper接口

**端口**：8084

**主要接口**：
- `GET /api/teacher/rank`：全校排名查询
- `GET /api/teacher/stats`：成绩分布统计
- `GET /api/teacher/warning`：学业预警查询

---

### 6. ai-service/（AI服务）

**作用**：提供AI智能问答功能

**关键文件**：
- `pom.xml`：服务依赖配置
- `AIServiceApplication.java`：服务启动类（端口8085）
- `application.yml`：服务配置文件
- `controller/AIController.java`：AI问答接口
- `mapper/GradeMapper.java`：成绩数据访问（用于AI分析）

**端口**：8085

**主要接口**：
- `POST /api/ai/chat`：AI智能问答

**功能**：
- 挂科查询
- 平均分查询
- 学习建议生成

---

### 7. gateway-service/（API网关服务）⭐ **关键服务**

**作用**：作为系统的统一入口，负责路由转发、负载均衡、跨域处理

**关键文件**：
- `pom.xml`：服务依赖配置（包含Spring Cloud Gateway依赖）
- `GatewayServiceApplication.java`：网关启动类（端口8888）
- `application.yml`：⭐ **路由配置文件**（定义所有路由规则）
- `config/CorsConfig.java`：⭐ **跨域配置类**

**端口**：8888（对外统一入口）

**为什么关键**：
- 所有前端请求都通过网关访问后端服务
- 统一处理路由转发、负载均衡、跨域等问题
- 是分布式系统的入口和核心

**路由规则**（在application.yml中定义）：
- `/api/login` → `user-service`
- `/api/student/**` → `student-service`
- `/api/grade/**` → `grade-service`
- `/api/teacher/**` → `teacher-service`
- `/api/ai/**` → `ai-service`

## 四、分布式系统的关键文件 ⭐⭐⭐

### 1. 服务注册与发现相关

#### （1）各服务的 application.yml 中的 Nacos 配置
```yaml
spring:
  cloud:
    nacos:
      discovery:
        server-addr: localhost:8848  # Nacos服务注册中心地址
```
**作用**：配置服务注册到Nacos，实现服务发现

**关键文件位置**：
- `user-service/src/main/resources/application.yml`
- `student-service/src/main/resources/application.yml`
- `grade-service/src/main/resources/application.yml`
- `teacher-service/src/main/resources/application.yml`
- `ai-service/src/main/resources/application.yml`
- `gateway-service/src/main/resources/application.yml`

#### （2）各服务的启动类中的 `@EnableDiscoveryClient` 注解
**作用**：启用服务发现功能，让服务自动注册到Nacos

**关键文件**：
- `UserServiceApplication.java`
- `StudentServiceApplication.java`
- `GradeServiceApplication.java`
- `TeacherServiceApplication.java`
- `AIServiceApplication.java`
- `GatewayServiceApplication.java`

---

### 2. API网关相关 ⭐⭐⭐

#### （1）gateway-service/application.yml ⭐ **最关键的配置文件**
**作用**：
- 定义所有路由规则
- 配置服务发现
- 配置负载均衡（lb://前缀）

**关键配置**：
```yaml
spring:
  cloud:
    gateway:
      discovery:
        locator:
          enabled: true  # 启用服务发现
          lower-case-service-id: true  # 使用小写服务名
      routes:
        - id: user-service-login
          uri: lb://user-service  # lb表示负载均衡
          predicates:
            - Path=/api/login
```

#### （2）gateway-service/config/CorsConfig.java
**作用**：配置CORS跨域，解决前后端分离架构下的跨域问题

---

### 3. 服务间调用相关 ⭐⭐

#### （1）grade-service/client/StudentServiceClient.java ⭐ **Feign客户端**
**作用**：
- 定义Feign客户端接口
- 声明式HTTP调用，简化服务间通信
- grade-service通过它调用student-service

**关键代码**：
```java
@FeignClient(name = "student-service", path = "/api/student")
public interface StudentServiceClient {
    @GetMapping("/{studentId}")
    Result<Student> getStudent(@PathVariable String studentId);
}
```

#### （2）grade-service/application.yml 中的 Feign 配置
```yaml
feign:
  client:
    config:
      default:
        connectTimeout: 5000  # 连接超时
        readTimeout: 5000     # 读取超时
```

#### （3）grade-service 启动类中的 `@EnableFeignClients` 注解
**作用**：启用Feign客户端功能

---

### 4. 公共模块 ⭐⭐

#### （1）common/pom.xml
**作用**：定义公共模块的依赖

#### （2）common/Result.java
**作用**：统一响应格式，所有API都返回Result对象

#### （3）common/entity/
**作用**：所有服务共享的实体类，保证数据模型一致性

---

### 5. 配置文件 ⭐

#### 各服务的 application.yml
**作用**：
- 配置服务端口
- 配置数据库连接
- 配置Nacos服务注册
- 配置MyBatis Plus
- 配置其他服务特定参数

**关键配置项**：
- `server.port`：服务端口
- `spring.application.name`：服务名称（用于服务发现）
- `spring.cloud.nacos.discovery.server-addr`：Nacos地址
- `spring.datasource.*`：数据库配置

---

## 五、分布式系统关键文件总结

### ⭐⭐⭐ 最关键的5个文件：

1. **gateway-service/application.yml**
   - 定义所有路由规则
   - 配置服务发现和负载均衡
   - 是分布式系统的入口配置

2. **各服务的 application.yml 中的 Nacos 配置**
   - 实现服务注册与发现
   - 没有它，服务无法被其他服务发现

3. **grade-service/client/StudentServiceClient.java**
   - 演示服务间调用
   - 展示Feign的使用方式

4. **microservices/pom.xml（父POM）**
   - 管理整个项目的依赖和版本
   - 没有它无法构建项目

5. **common/Result.java**
   - 统一响应格式
   - 保证所有服务返回格式一致

### ⭐⭐ 重要的配置文件：

- **各服务的启动类**：包含`@EnableDiscoveryClient`注解
- **gateway-service/config/CorsConfig.java**：跨域配置
- **各服务的 application.yml**：服务特定配置

---

## 六、启动顺序

1. **启动Nacos**（服务注册中心）
2. **启动业务服务**（顺序无关）：
   - user-service (8081)
   - student-service (8082)
   - grade-service (8083)
   - teacher-service (8084)
   - ai-service (8085)
3. **最后启动网关**：
   - gateway-service (8888)

---

## 七、服务间调用流程示例

```
前端请求 → gateway-service (8888)
         ↓
   路由转发到 grade-service (8083)
         ↓
   grade-service 通过 Feign 调用 student-service (8082)
         ↓
   返回结果给前端
```

---

## 八、总结

**分布式系统的核心**：
1. **服务注册与发现**：通过Nacos实现
2. **API网关**：通过Spring Cloud Gateway实现
3. **服务间调用**：通过OpenFeign实现
4. **统一响应格式**：通过common模块的Result类实现

**关键文件的作用**：
- 配置文件（application.yml）：定义服务的行为
- 启动类：启用分布式功能
- Feign客户端：实现服务间调用
- 网关配置：实现统一入口和路由
