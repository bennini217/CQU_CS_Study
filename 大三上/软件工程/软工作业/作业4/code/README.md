# 作品版权登记系统

## 项目概述

本系统是一个作品版权登记系统，主要功能是"登记绘画版权"。系统可以检查绘画分辨率、生成图像特征值、进行相似度比对，并完成版权登记。

## 功能说明

### 主要功能

1. **图像分辨率检查**：检查上传的图像是否满足最小分辨率要求（800×600像素）
2. **特征值生成**：使用Perceptual Hash (pHash)算法生成图像特征值
3. **相似度比对**：使用汉明距离计算图像相似度
4. **版权登记**：如果相似度低于阈值，则进行版权登记；否则拒绝并显示最相似的已存证作品

### 技术实现

- **pHash算法**：使用`imagehash`库的`phash`函数生成感知哈希
- **汉明距离**：使用`imagehash`库计算两个哈希值之间的汉明距离
- **数据存储**：使用JSON文件存储已登记的作品信息

## 使用示例

1. 启动程序后，选择"1. 登记绘画版权"
2. 输入作品信息：
   - 标题：例如"我的画作"
   - 作者：例如"张三"
   - 作品类型：例如"油画"
   - 图像文件路径：例如"image.jpg"
3. 系统会自动检查分辨率、生成特征值、进行相似度比对
4. 如果通过，显示登记成功；如果失败，显示失败原因和最相似的已存证作品

## 注意事项

1. 图像文件必须是有效的图像格式（JPG、PNG等）
2. 图像分辨率必须至少为800×600像素
3. 相似度阈值默认为10（汉明距离），可在系统初始化时调整
4. 数据库文件使用JSON格式存储，适合小规模使用
