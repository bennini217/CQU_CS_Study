## 一、项目概述

### 1.1 项目背景

随着数字艺术和绘画作品的日益增多，版权保护变得越来越重要。本系统旨在开发一个作品版权登记系统，通过技术手段自动检测重复作品，保护创作者的合法权益。

### 1.2 项目目标

开发一个完整的作品版权登记系统，实现以下核心功能：
- 用户上传绘画作品并填写基本信息
- 系统自动检查图像分辨率
- 自动生成图像特征值（哈希指纹）
- 与已存证作品进行相似度比对
- 根据相似度决定是否进行版权登记

### 1.3 技术选型

- **开发语言**：Python 3.7+
- **后端框架**：Flask 2.3+
- **前端技术**：HTML5 + CSS3 + JavaScript (原生)
- **图像处理**：Pillow + imagehash
- **数据存储**：JSON文件
- **算法**：Perceptual Hash (pHash) + 汉明距离

## 二、需求分析

### 2.1 功能需求

根据作业要求，系统需要实现"登记绘画版权"用例，具体流程如下：

1. **用户输入**：
   - 上传绘画图像文件
   - 填写作品基本信息（标题、作者、登记时间、作品类型等）

2. **系统处理**：
   - 检查绘画分辨率（至少800×600像素）
   - 自动生成特征值（使用pHash算法提取图像哈希指纹）
   - 将该特征值与库中已存证绘画的特征值进行比对
   - 计算相似度（使用汉明距离）

3. **系统输出**：
   - 如果相似度低于阈值：进行版权登记
   - 如果相似度高于阈值：拒绝登记，并对比展示与之最相似的一副已存证绘画

### 2.2 非功能需求

- **性能要求**：图像处理响应时间 < 5秒
- **可用性要求**：提供友好的Web界面
- **可维护性要求**：代码结构清晰，模块化设计
- **可扩展性要求**：易于添加新的功能模块

## 四、系统实现

### 4.1 核心算法实现

#### 4.1.1 Perceptual Hash (pHash) 算法

使用 `imagehash` 库实现pHash算法：

```python
def generate_hash(image_path: str) -> str:
    """使用Perceptual Hash算法生成图像特征值"""
    with Image.open(image_path) as img:
        hash_value = imagehash.phash(img)
        return str(hash_value)
```

pHash算法原理：
1. 将图像缩放到固定尺寸（通常32×32）
2. 转换为灰度图
3. 应用离散余弦变换（DCT）
4. 提取低频分量
5. 生成64位哈希值

#### 4.1.2 汉明距离计算

使用汉明距离计算两个哈希值的差异：

```python
def calculate_hamming_distance(self, hash1: str, hash2: str) -> int:
    """计算两个哈希值之间的汉明距离"""
    h1 = imagehash.hex_to_hash(hash1)
    h2 = imagehash.hex_to_hash(hash2)
    return h1 - h2  # imagehash库重载了减号运算符
```

汉明距离越小，图像越相似。默认阈值为10。
