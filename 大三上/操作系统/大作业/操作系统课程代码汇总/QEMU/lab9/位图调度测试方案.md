# 位图调度功能测试方案

## 测试目标
验证位图调度优化是否正确工作，确保高优先级任务优先执行。

## 测试方法

### 方法1: 使用现有的 `top` 命令（最简单）

1. **在QEMU中运行内核后，输入命令：**
   ```
   top
   ```
   然后按回车

2. **观察输出：**
   - 应该能看到所有就绪任务及其优先级
   - 验证任务是否按优先级正确组织

---

### 方法2: 添加测试任务（推荐）

在 `src/main.c` 中添加测试任务，创建多个不同优先级的任务来验证调度。

#### 修改 `src/main.c`：

在 `ShellTaskInit(&g_shellCB);` 之前添加测试任务：

```c
// 测试任务函数
OS_SEC_TEXT void TestTask1(uintptr_t param1, uintptr_t param2, uintptr_t param3, uintptr_t param4)
{
    U32 count = 0;
    while (1) {
        PRT_Printf("[Task1-Prio5] Count: %d\n", count++);
        PRT_TaskDelay(100);  // 延时100个tick，让其他任务有机会运行
    }
}

OS_SEC_TEXT void TestTask2(uintptr_t param1, uintptr_t param2, uintptr_t param3, uintptr_t param4)
{
    U32 count = 0;
    while (1) {
        PRT_Printf("[Task2-Prio10] Count: %d\n", count++);
        PRT_TaskDelay(100);
    }
}

OS_SEC_TEXT void TestTask3(uintptr_t param1, uintptr_t param2, uintptr_t param3, uintptr_t param4)
{
    U32 count = 0;
    while (1) {
        PRT_Printf("[Task3-Prio15] Count: %d\n", count++);
        PRT_TaskDelay(100);
    }
}

// 在main函数中，ShellTaskInit之前添加：
void CreateTestTasks(void)
{
    U32 ret;
    TskHandle taskHandle;
    struct TskInitParam param = {0};

    // 创建优先级5的任务（高优先级）
    param.taskEntry = (TskEntryFunc)TestTask1;
    param.taskPrio = 5;
    param.stackSize = 0x1000;
    param.args[0] = 0;
    ret = PRT_TaskCreate(&taskHandle, &param);
    if (ret == OS_OK) {
        PRT_TaskResume(taskHandle);
        PRT_Printf("Created TestTask1 with priority 5\n");
    }

    // 创建优先级10的任务（中优先级）
    param.taskEntry = (TskEntryFunc)TestTask2;
    param.taskPrio = 10;
    ret = PRT_TaskCreate(&taskHandle, &param);
    if (ret == OS_OK) {
        PRT_TaskResume(taskHandle);
        PRT_Printf("Created TestTask2 with priority 10\n");
    }

    // 创建优先级15的任务（低优先级）
    param.taskEntry = (TskEntryFunc)TestTask3;
    param.taskPrio = 15;
    ret = PRT_TaskCreate(&taskHandle, &param);
    if (ret == OS_OK) {
        PRT_TaskResume(taskHandle);
        PRT_Printf("Created TestTask3 with priority 15\n");
    }
}
```

然后在 `main()` 函数中调用：
```c
CreateTestTasks();
ShellTaskInit(&g_shellCB);
```

#### 预期结果：
- Task1 (优先级5) 应该执行最频繁
- Task2 (优先级10) 执行频率中等
- Task3 (优先级15) 执行频率最低
- 输出应该显示优先级5的任务输出最多

### 方法3: 添加调试命令查看位图状态

在 `src/kernel/shell/shmsg.c` 中添加新命令查看位图：

```c
// 在ShellTask函数中添加新命令
else if(cmd[0]=='b' && cmd[1]=='i' && cmd[2]=='t' && cmd[3]=='m' && cmd[4]=='a' && cmd[5]=='p'){
```

然后输入命令 `bitmap` 查看位图状态。

## 常见问题

### Q: 如果编译出错？
A: 检查是否所有修改都已正确应用，特别是结构体定义和函数声明。

### Q: 如果系统启动后没有输出？
A: 检查串口初始化是否正确，或者添加更多调试输出。

### Q: 如何确认位图调度真的在工作？
A: 
1. 使用 `top` 命令查看任务
2. 创建多个不同优先级的任务
3. 观察执行顺序是否符合优先级
