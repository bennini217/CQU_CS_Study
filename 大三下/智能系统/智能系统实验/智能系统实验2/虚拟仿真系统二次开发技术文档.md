### 1.3 分层架构与调用链路

```
Router 层  →  Service 层  →  DAO 层  →  Model 层  →  数据库
(API入口)     (业务逻辑)     (数据操作)   (表映射)
```

**核心设计模式**：
- **泛型基类复用**：`BaseDAO` 和 `BaseService` 通过 Python 泛型，让所有模块共享同一套 CRUD 方法。
- **依赖注入**：通过 `Depends(get_db)` 将数据库连接自动传入每个请求。
- **单例实例化**：每个模块的 DAO 和 Service 在文件末尾创建一个全局实例（如 `user_service = UserService()`）。

### 1.4 各层详细说明

#### 1.4.1 应用入口（`app/main.py`）

```python
# 创建 FastAPI 应用
app = FastAPI(title="交通信号灯控制系统API", version="1.0.0")

# 注册中间件
app.add_middleware(DBSessionMiddleware)   # 数据库会话管理
app.add_middleware(CORSMiddleware, ...)   # 允许前端跨域访问

# 注册路由
app.include_router(user.router)       # 用户模块
app.include_router(websocket.router)  # WebSocket
```

**扩展新模块时**，只需在 `main.py` 中再添加一行 `app.include_router(新模块.router)`。

#### 1.4.2 数据库配置（`app/database.py`）

- `engine`：数据库连接引擎，配置了连接池
- `SessionLocal`：会话工厂，每次请求创建一个新的数据库会话
- `Base`：所有 ORM 模型的基类
- `get_db()`：FastAPI 依赖注入函数，请求开始时创建会话，结束时自动关闭

#### 1.4.3 Model 层（以 `app/models/user.py` 为例）

```python
class User(Base):
    __tablename__ = "users"                    # 数据库表名
    id = Column(Integer, primary_key=True)     # 主键，自增
    name = Column(String(50), nullable=False)  # 姓名字段，不能为空
```

#### 1.4.4 Schema 层（以 `app/schemas/user.py` 为例）

定义四种数据类型：

| Schema | 用途 | 说明 |
|--------|------|------|
| `UserBase` | 公共字段 | `name: str` |
| `UserCreate` | 创建请求体 | 继承 UserBase |
| `UserUpdate` | 更新请求体 | `name` 可选 |
| `UserResponse` | 响应数据 | 比 UserBase 多了 `id` |
| `PaginatedResponse` | 分页响应 | 通用，所有模块复用 |

#### 1.4.5 DAO 层（`app/dao/base.py` + `app/dao/user.py`）

BaseDAO 提供通用方法：

| 方法 | 功能 |
|------|------|
| `get(id)` | 按 ID 查单条 |
| `get_multi(skip, limit)` | 分页查询 |
| `create(obj_in)` | 新增记录 |
| `update(db_obj, obj_in)` | 更新记录 |
| `delete(id)` | 删除记录 |
| `get_multi_with_total(skip, limit)` | 分页+总数 |

`UserDAO` 继承即可复用：
```python
class UserDAO(BaseDAO[User, UserCreate, UserUpdate]):
    pass
```

#### 1.4.6 Service 层（`app/service/base.py` + `app/service/user.py`）

BaseService 封装通用业务逻辑。UserService 在其基础上添加了**用户名不能重复**的校验。

#### 1.4.7 Router 层（`app/routers/user.py`）

| 方法 | 路径 | 功能 |
|------|------|------|
| `POST` | `/api/users/` | 创建用户 |
| `GET` | `/api/users/` | 分页列表 |
| `GET` | `/api/users/{id}` | 查询单个 |
| `PUT` | `/api/users/{id}` | 更新用户 |
| `DELETE` | `/api/users/{id}` | 删除用户 |
| `GET` | `/api/users/search/{name}` | 模糊搜索 |

#### 1.4.8 中间件（`app/middleware.py`）

- `DBSessionMiddleware`：为每个 HTTP 请求创建独立的数据库会话，请求结束后自动关闭
- `WebSocketCORSMiddleware`：处理 WebSocket 连接的跨域问题

### 2.3 入口文件：main.js

这个文件是前端应用的**启动入口**，它做的事情是：

```javascript
import { createApp } from 'vue'       // 导入 Vue
import App from './App.vue'           // 导入根组件
import store from './store'           // 导入 Vuex 状态管理
import router from './router'         // 导入路由配置
import axios from 'axios'             // 导入 HTTP 请求库

// 1. 配置 Axios 拦截器：当后端返回 403（无权限）时，自动跳转到登录页
axios.interceptors.response.use(response => {
  return response
}, error => {
  if (error.response && error.response.status === 403) {
    store.commit('REMOVEUSER')        // 清除用户信息
    router.push({ path: '/login' })   // 跳转到登录页
  }
  return Promise.reject(error)
})

// 2. 创建 Vue 应用，安装插件
const app = createApp(App)
app.use(router)    // 安装路由插件（让页面能根据 URL 跳转）

// 3. 注册 Element Plus 的所有图标组件（让每个页面都能用 <el-icon>）
for (const [key, component] of Object.entries(ElementPlusIconsVue)) {
  app.component(key, component)
}

// 4. 把应用挂载到 index.html 中的 <div id="app"> 上
```

### 2.5 路由配置：router/index.js

路由配置决定了**哪个 URL 对应哪个页面组件**，同时控制**菜单栏显示什么**。

```javascript
const routes = [
  {
    path: "/database",           // URL 路径
    component: Dashboard,        // 这个路径对应的布局组件
    meta: {
      menu: true,                // ☑ 在侧边栏菜单中显示
      name: "数据库",            // 菜单上显示的名字
      icon: "home",              // 菜单前的图标
      type: "0"                  // 菜单类型
    },
    children: [                  // 子路由（会在菜单中显示为下拉子项）
      {
        name: 'user',
        path: '/user',           // 实际访问路径是 /user
        component: UserMain,     // 对应的页面组件
        meta: {
          menu: true,            // ☑ 在菜单中显示
          name: "用户管理",
          icon: "home",
          type: "0"
        }
      },
      {
        name: 'car',
        path: '/car',
        component: Main,         // 车流量管理（目前是占位组件）
        meta: { menu: true, name: "车流量管理", icon: "home", type: "0" }
      }
    ]
  }
]

// 创建路由实例
export default createRouter({
  history: createWebHistory(),   // 使用 HTML5 History 模式
  routes: routes
})
```

**关键知识点**：
- `path`：浏览器地址栏中的 URL
- `component`：该 URL 对应的 `.vue` 文件
- `meta.menu: true`：表示要在左侧菜单中显示
- `meta.name`：菜单上显示的中文名
- `children`：子菜单，访问时会自动嵌套显示

### 2.6 侧边栏菜单自动生成：menu.vue

`menu.vue` 会**自动读取路由配置，生成菜单树**，不需要手动写菜单 HTML。

核心逻辑：

```javascript
// 从路由配置生成菜单
const generateMenuFromRoutes = () => {
  const routes = router.getRoutes()     // 获取所有路由
  const menuItems = []

  routes.forEach(route => {
    // 只处理 meta.menu === true 的路由（不需要在菜单中显示的路由会被跳过）
    if (route.meta?.menu === true) {
      const menuItem = {
        name: route.meta.name,          // 菜单显示名称
        icon: route.meta.icon,          // 菜单图标
        path: route.path,               // 点击后跳转的路径
        children: []                    // 子菜单
      }

      // 如果有子路由，也把子路由中 meta.menu === true 的加进来
      if (route.children) {
        route.children.forEach(child => {
          if (child.meta?.menu === true) {
            menuItem.children.push({
              name: child.meta.name,
              path: child.path
            })
          }
        })
      }

      menuItems.push(menuItem)
    }
  })

  return menuItems
}
```

**结论**：添加新页面时，只需要在 `router/index.js` 中添加路由并设置 `meta.menu: true`，菜单就会自动出现，不需要修改 `menu.vue`。

```javascript
  }

const get = async function(url, params = {}) { /* 类似上面 */ }

const del = async function(url, data = {}) { /* 类似上面 */ }
```

**在页面组件中的使用方式**：

### 2.8 状态管理：store/index.js

Vuex 用于在多个组件之间共享数据。当前系统只管理了用户登录状态：

```javascript
import { createStore } from 'vuex'

export default createStore({
  state: {
    user: {},    // 当前登录用户的信息
  },
  mutations: {
    SAVEUSER(state, user) {
      state.user = user
      localStorage.setItem("user", JSON.stringify(user))  // 持久化存储
    },
    REMOVEUSER(state) {
      state.user = {}
      localStorage.removeItem('user')                     // 清除存储
    }
  },
  actions: {
    saveUser(context, user) { context.commit('SAVEUSER', user) },
    removeUser(context) { context.commit('REMOVEUSER') }
  }
})
```

**在任意组件中访问用户信息**：
```javascript
import { useStore } from 'vuex'
const store = useStore()
console.log(store.state.user)   // 获取当前用户
store.dispatch('saveUser', { name: '张三' })   // 保存用户
```

#### 2.9.2 数据定义（响应式变量）

```javascript
// ref()：定义一个可变的单值变量，修改后页面会自动更新
const keyword = ref("")              // 搜索关键字
const addDialogVisible = ref(false)  // 新增对话框是否显示
const editDialogVisible = ref(false) // 编辑对话框是否显示
const selectedRows = ref([])         // 表格中勾选的行（用于批量删除）

// reactive()：定义一个可变的复杂对象，修改后页面会自动更新
const pageInfo = reactive({
  type: 'query',           // 当前模式：'query'=普通查询，'search'=搜索模式
  keyword: '',             // 搜索关键字
  pageIndex: 1,            // 当前第几页
  pageSize: 20,            // 每页显示多少条
  count: 0,                // 总共有多少条记录
  entitys: []              // 当前页的数据列表

const editForm = reactive({

  name: ""                 // 正在编辑的用户名

```

**初学提示**：
- `ref()` 和 `reactive()` 是 Vue3 的**响应式**数据定义方式。通俗说就是：修改变量的值，页面会自动跟着变。
- `ref()` 用于简单的值（字符串、数字、布尔），在 JS 中访问需要用 `.value`（如 `keyword.value`），在模板中直接用名字。
- `reactive()` 用于对象，直接访问属性即可（如 `pageInfo.pageIndex`）。

#### 2.9.3 核心方法详解

**① 加载数据：`initData()` 和 `requestList()`**

```javascript
// 页面挂载后自动调用，加载第一页数据
async function initData() {
  const pageSize = pageInfo.pageSize || 20
  const pageIndex = pageInfo.pageIndex || 1
  const params = {
    "findType": pageInfo.type,   // 'query' 或 'search'
    "page": pageIndex,
    "size": pageSize
  }
  await requestList(params)
}

// 实际发请求获取数据
async function requestList(params) {
  // 1. 构造分页参数：前端的 page/size → 后端的 skip/limit
  const queryParams = {
    skip: (params.page - 1) * params.size,
    limit: params.size
  }

  // 2. 根据类型拼接 URL
  var url = "/api/users/"    // 普通查询
  if (params.findType === "search") {
    url = `/api/users/search/${encodeURIComponent(params.keyword)}`  // 模糊搜索
  }

  // 3. 发 GET 请求
  var res = await get(url, queryParams)
  const resData = res.data

  // 4. 把后端返回的数据填到 pageInfo 中，页面自动更新
  pageInfo.entitys = resData.items || []      // 当前页数据
  pageInfo.count = resData.total || 0         // 总记录数
  pageInfo.totalPages = resData.pages || 1    // 总页数
  pageInfo.pageIndex = resData.page || 1      // 当前页码
  pageInfo.pageSize = resData.size || params.size
}
```

**② 新增用户：`onAddClickHandler()`**

```javascript
async function onAddClickHandler() {
  // 1. 检查输入是否为空
  if (!form.form.name.trim()) {
```

```python
from fastapi import APIRouter, Depends, HTTPException, status
from sqlalchemy.orm import Session
from app.database import get_db
from app.schemas.carmanage import CarRecordCreate, CarRecordUpdate, CarRecordResponse
from app.schemas.user import PaginatedResponse
from app.service.carmanage import car_record_service

router = APIRouter(prefix="/api/car-records", tags=["car-records"])

@router.post("/", response_model=CarRecordResponse, status_code=status.HTTP_201_CREATED)
def create_record(record: CarRecordCreate, db: Session = Depends(get_db)):
    return car_record_service.create(db, obj_in=record)

@router.get("/", response_model=PaginatedResponse)
def list_records(skip: int = 0, limit: int = 100, db: Session = Depends(get_db)):
    return car_record_service.get_multi_with_total(db, skip=skip, limit=limit)

@router.get("/{record_id}", response_model=CarRecordResponse)
def get_record(record_id: int, db: Session = Depends(get_db)):
    record = car_record_service.get(db, id=record_id)
    if not record:
        raise HTTPException(status_code=404, detail="记录不存在")
    return record

@router.put("/{record_id}", response_model=CarRecordResponse)
def update_record(record_id: int, record: CarRecordUpdate, db: Session = Depends(get_db)):
    updated = car_record_service.update(db, id=record_id, obj_in=record)
    if not updated:
        raise HTTPException(status_code=404, detail="记录不存在")
    return updated

@router.delete("/{record_id}", status_code=status.HTTP_204_NO_CONTENT)
def delete_record(record_id: int, db: Session = Depends(get_db)):
    deleted = car_record_service.delete(db, id=record_id)
    if not deleted:
        raise HTTPException(status_code=404, detail="记录不存在")
    return None
```
